### 🌐 FANET Routing Research

<img src="https://img.shields.io/badge/SOLO_RESEARCH-7C3AED?style=flat-square" />
<img src="https://img.shields.io/badge/STATUS-In_Progress-F59E0B?style=flat-square" />

**Flying Ad Hoc Network Routing Stability Research**

드론 애드혹 네트워크의 동적인 토폴로지 환경에서 라우팅 안정성을 분석하는 개인 연구입니다.

**What I Worked On**

- ns-3 기반 OLSR 라우팅 시뮬레이션 구성
- Multi-Point Relay(MPR) 선택 알고리즘 분석
- Link Expiration Time(LET) 기반 경로 전환 실험
- Python을 활용한 실험 자동화 및 로그 분석
- Packet Delivery Ratio(PDR) 결과 시각화

**Research Topics**

`OLSR` `MPR` `LET` `Routing Stability` `Network Simulation`

**Development Environment**

`C++` `Python` `ns-3` `Linux`
