<img src="https://img.shields.io/badge/STATUS-In_Progress-F59E0B?style=flat-square" />

드론 애드혹 네트워크의 동적인 토폴로지 환경에서 라우팅 안정성을 분석하는 개인 연구입니다.

**What I Implemented**

- ns-3 기반 OLSR 라우팅 시뮬레이션 구성

- Link Expiration Time(LET) 기반 경로 전환 실험
- Python을 이용한 실험 실행 및 로그 자동화
- Packet Delivery Ratio(PDR) 결과 시각화

**Research Topics**

`OLSR` `MPR` `LET` `Routing Stability` `Network Simulation`

**Environment**

`C++` `Python` `ns-3` `Ubuntu` `WSL`

**Elden Ring Equipment Preset Management Utility**

**What I Implemented**

- 게임 메모리에서 장비 및 인벤토리 데이터 읽기
- 무기, 방어구, 탈리스만 등 장비 구성 식별
- 캐릭터별 장비 프리셋 저장 및 파일 관리
- 키보드 단축키 기반 프리셋 관리 기능
- 게임패드 입력 및 프리셋 선택 UI 구현 작업
- GitHub Actions 기반 Windows 빌드 자동화

**Technical Challenges**

- 게임 버전에 따른 데이터 구조 및 메모리 접근
- 장비 ID와 실제 인벤토리 항목의 일치 여부 검증
- Windows 환경에서 실행 가능한 독립 프로그램 빌드

**Tech Stack**

`Python` `Windows` `Game Data Analysis` `Automation`

> 일부 장비 복원 및 게임패드 동작은 실제 게임 환경에서 추가 검증이 필요합니다.
