**팀 구현 범위:** 카메라 인식과 ToF 거리 처리는 현재 별도로 동작합니다. 두 입력을 결합한 위험도 판단과 자동 보행 경고는 미완성입니다.

**Tech Stack:** `Kotlin` `Android` `ONNX Runtime` `YOLOX-Nano` `USB` `ToF`
